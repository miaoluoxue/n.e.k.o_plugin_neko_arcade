# 🏗️ 运行机制总纲（简版）

> 插件架构的**概览**，供面板快速了解。
> 完整机制说明（通信规则 / 输出架构 / 交互流程）在 GitHub 仓库：
> **`docs/ARCHITECTURE.md`**。

## 一句话

**游戏适配插件，不是插件适配游戏**——插件是"游戏大脑总管家"，
游戏只做玩法逻辑，情感 / 图片 / 语音 / 帮助 / 路由全部由插件统一负责。

## 数据流

```
玩家输入 → parse_input 路由 → 游戏 handle_action 返回结构化结果
    → brain 统一编排（推送 / 情感 / 帮助 / 状态锚）
    → 猫娘在聊天窗回应
```

## 关键机制

| 机制 | 说明 |
|------|------|
| 自动发现 | 启动扫描 `games/`，新增游戏零登记 |
| 输出通道 | 游戏不推送，brain 统一 push_message + summary |
| 状态锚 | 游戏进行中定期注入上下文，LLM 不脱节 |
| 命令专属 | 每游戏指令带前缀，跨游戏不串台 |
