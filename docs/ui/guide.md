# 🐱 猫娘小游戏 · 使用指南

> 喵呜～欢迎来到猫娘小游戏！这里是教你怎么和我一起玩的小手册，请放心食用～ 💕

## ✨ 怎么开始玩

超简单的！只要在聊天里对我喊一声游戏名就可以啦：

- **「钓鱼」** → 我们一起去河边钓鱼喵！🎣
- **「修仙」** → 开启修仙之旅，突破境界飞升！🧘
- **「塔罗牌」** → 让我给你算一卦，看看今天的运势！🔮
- **「猫猫进化」** → 领养一只小猫，陪我一起长大！🐱

> 也可以打开面板，点一下游戏卡片上的 **▶ 开始**，然后在指挥台输入指令哦～

## 💬 游戏里怎么说话

| 你想做什么 | 对我这样说 |
|-----------|-----------|
| 开始玩一个游戏 | 说游戏名，比如「钓鱼」「修仙」 |
| 看这个游戏有什么指令 | 说「**帮助**」喵 |
| 查看自己的状态 | 说「**猫猫状态**」「**修仙状态**」这类指令 |
| 不玩了 | 说「不玩了」或者点面板的「⏹ 停止」 |

> 💡 每个游戏的指令都是**专属命名**（猫猫状态 / 修仙状态 / 鱼店…），
> 不会串来串去喵～具体指令以游戏帮助图为准！

## 🎁 猫娘会做什么

- 你玩游戏，我会在旁边**陪你加油打气**，赢了夸你、输了安慰你～
- 钓到稀有鱼、抽到好牌的时候，我会给你**发图片卡片**记录高光时刻！
- 我会**记住你玩过什么**，下次见面还记得上次的冒险喵～

## ❓ 常见问题

| 问题 | 解决 |
|------|------|
| 喊游戏名没有反应 | 检查插件有没有启用喵；面板上能看到游戏卡片就 OK |
| 帮助图没有弹出来 | 重启一下插件再试试喵～ |
| 语音没有声音 | 语音是宿主在播的，去宿主的语音设置看看有没有打开喵 |
