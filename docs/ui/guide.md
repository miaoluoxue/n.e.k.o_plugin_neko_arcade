# 🐱 猫娘小游戏 · 使用指南

> 简单版使用指南（面板展示用）。完整开发者文档在 GitHub 仓库 `docs/` 目录。

## 快速开始

1. 启用插件后，聊天里直接对猫娘说游戏名（如「钓鱼」「修仙」「塔罗牌」）
2. 或者在面板点游戏卡片 → 「▶ 开始」→ 在指挥台输入指令
3. 进游戏后说「帮助」，猫娘会发一张该游戏的指令图

## 怎么玩

| 你想做的事 | 怎么说 |
|-----------|--------|
| 开始玩一个游戏 | 说游戏名，如「钓鱼」「修仙」「猫猫进化」 |
| 看当前游戏指令 | 说「帮助」 |
| 停止游戏 | 说「不玩了」或在面板点「⏹ 停止」 |

> 💡 每个游戏的指令都是专属命名（猫猫状态 / 修仙状态 / 鱼店…），
> 不会串台；具体指令以游戏帮助图为准。

## 常见问题

| 问题 | 解决 |
|------|------|
| 说游戏名没反应 | 检查插件已启用；面板「游戏卡片」确认游戏存在 |
| 帮助图没弹出 | 重启插件后再试 |
| 语音不响 | TTS 由宿主播放，检查宿主语音配置 |
