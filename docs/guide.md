# 🐱 猫娘小游戏 · 使用指南

## 快速开始

1. N.E.K.O 插件管理 → 启用「猫娘小游戏」
2. 控制面板：选择游戏卡片 → 输入指令
3. 也可以在聊天里对 AI 说「钓鱼」，大脑自动路由

## 面板功能

| 区域 | 说明 |
|------|------|
| 猫娘状态 | 心情、情绪百分比、当前会话、开始/停止 |
| 游戏卡片 | 图标、描述、开关、状态；点击选中 |
| 指挥台 | 输入指令（钓鱼 / 鱼缸 / 鱼市 / 鱼店…） |
| 对话区 | 猫娘的话（情感渲染） |
| 记忆 | 各游戏游玩局数、最近游玩 |

## 游戏指令

> ⚠️ **命令是游戏专属的**：每个游戏的指令带专属前缀（猫猫状态 / 修仙状态 /
> 鱼店 / 海龟汤状态…），不会跨游戏串台。**完整指令以各游戏帮助图为准**
> （进游戏后说「帮助」即弹出），本页只演示玩法流程。

### 演示：钓鱼

| 指令 | 说明 |
|------|------|
| `钓鱼` / `钓鱼 3` | 抛竿 1 次 / 连钓 3 次 |
| `鱼缸` / `升级鱼缸` | 查看收藏 / 扩容（+5 容量 +2 每日钓次） |
| `鱼市` / `售鱼 全部` | 出售鱼获换鱼蛋 |
| `换竿 疾风短竿` / `换饵 香谷鱼饵` | 切换装备 |
| `鱼店` / `购买 疾风短竿` | 购买鱼竿鱼饵 |
| `帮助` | 玩法帮助 |

> 其他游戏玩法类似：聊天里说游戏名进入（如「修仙」「塔罗牌」「猫猫进化」），
> 然后说「帮助」看该游戏的专属指令图。当前内置哪些游戏，以**插件面板的游戏卡片**为准。

## 聊天对话

直接在聊天框对 AI 说游戏指令即可，插件自动识别：

- **「钓鱼」** → 抛竿钓鱼 1 次
- **「钓鱼 3」** → 连钓 3 次
- **「鱼缸」** → 查看收藏
- **「猜硬币 正」** → 猜正面
- **「我想钓鱼」** → 收到游戏邀请和玩法说明
- **「帮助」** → 当前游戏帮助

## 猫娘行为

- 游戏结果 → 猫娘情感渲染（游戏模板或 LLM 生动生成）
- 心情会衰减，说话风格随心情变化（激动多话、失落简短）
- 她会主动说话：游戏中等待时碎碎念、久不玩会邀请你
- 高光事件（传说鱼等）推送图片卡片
- 人设自动从主项目 characters.json 加载

## 常见问题

| 问题 | 解决 |
|------|------|
| 面板显示未启动 | 检查插件是否启用 |
| 没有小游戏 | 确认 games/ 目录下有游戏包 |
| 猫娘没感情反应 | 未配置 LLM 时走模板，配置 LLM 后效果更好 |
| 语音不响 | 语音由宿主自动播放 chat 文字；TTS 配置在宿主侧，插件只保证短句 |
| 猫娘说了一句后又重复一句 | 属于插件小 bug，更新插件到最新版即可 |
