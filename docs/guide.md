# 🐱 猫娘小游戏 · 使用指南

## 快速开始

1. N.E.K.O 插件管理 → 启用「猫娘小游戏」
2. 控制面板：选择游戏卡片 → 输入指令
3. 也可以在聊天里对 AI 说「钓鱼」，大脑自动路由

## 面板功能

| 区域 | 说明 |
|------|------|
| 猫娘状态 | 心情、情绪百分比、当前会话、开始/停止 |
| 游戏卡片 | 图标、描述、开关、状态；点击选中 |
| 指挥台 | 输入指令（钓鱼 / 鱼缸 / 鱼市 / 商店…） |
| 对话区 | 猫娘的话（情感渲染） |
| 记忆 | 各游戏游玩局数、最近游玩 |

## 游戏指令

### 钓鱼

| 指令 | 说明 |
|------|------|
| `钓鱼` / `钓鱼 3` | 抛竿 1 次 / 连钓 3 次 |
| `鱼缸` / `升级鱼缸` | 查看收藏 / 扩容（+5 容量 +2 每日钓次） |
| `鱼市` / `售鱼 全部` | 出售鱼获换鱼蛋 |
| `换竿 疾风短竿` / `换饵 香谷鱼饵` | 切换装备 |
| `商店` / `购买 疾风短竿` | 购买鱼竿鱼饵 |
| `帮助` | 玩法帮助 |

### 猜硬币

| 指令 | 说明 |
|------|------|
| `猜硬币 正` | 猜硬币正面 |
| `猜硬币 反` | 猜硬币反面 |
| `帮助` | 玩法帮助 |

## 聊天对话

直接在聊天框对 AI 说游戏指令即可，插件自动识别：

- **「钓鱼」** → 抛竿钓鱼 1 次
- **「钓鱼 3」** → 连钓 3 次
- **「鱼缸」** → 查看收藏
- **「猜硬币 正」** → 猜正面
- **「我想钓鱼」** → 收到游戏邀请和玩法说明
- **「帮助」** → 当前游戏帮助

## 猫娘行为

- 游戏结果 → 猫娘情感渲染（游戏模板或 LLM 生动生成）
- 心情会衰减，说话风格随心情变化（激动多话、失落简短）
- 她会主动说话：游戏中等待时碎碎念、久不玩会邀请你
- 高光事件（传说鱼等）推送图片卡片
- 人设自动从主项目 characters.json 加载

## 常见问题

| 问题 | 解决 |
|------|------|
| 面板显示未启动 | 检查插件是否启用 |
| 没有小游戏 | 确认 games/ 目录下有游戏包 |
| 猫娘没感情反应 | 未注入 LLM 时走模板，配置 LLM 后效果更好 |
| 语音不响 | TTS 接口预留中，后续版本启用 |
| 猫娘把同一句话说了两遍（双重回复） | 这是插件 bug，不是宿主问题：某个游戏的 `handle_action` 自己推送了文本、又把同一文本放进返回的 message/summary，导致宿主 LLM 复述。游戏作者应读 [rules.md §2.5](rules.md) 的输出契约修正 |

## 常见问题：为什么猫娘会把同一句话重复说？

**现象**：玩「历史上的今天」等游戏时，猫娘可能连着发两条几乎一样的话，例如：

```
YUI: 哇,15 条呢!主人想听哪个年代的故事?
YUI: 哇,15 条呢!主人想听哪个年代的故事? 今天共 15 条历史大事
```

**原因**：插件把游戏结果通过**两条通道**送出去——
1. 游戏自己直接推送文本到聊天窗；
2. 插件把同一文本作为 summary 返回给宿主，宿主让主 LLM 复述了一遍。

这是**插件开发问题**，不是你的使用问题。修好后一条动作只会看到
「游戏输出 + 猫娘自然回应」两条不同的内容。如果你遇到，告诉插件作者
读一下 [rules.md §2.5](rules.md) 就好。
