# 🎮 猫娘小游戏 (neko_arcade)

> 让猫娘陪你玩各种小游戏——钓鱼、海龟汤、猜硬币、修仙、塔罗牌……一个插件，无限可能。

N.E.K.O 插件 · 插件化小游戏聚合器 · 支持聊天/语音自然语言直接开玩

## ✨ 功能特性

- 🧩 **插件化游戏架构**：`games/` 目录放一个小游戏包即完成接入，零改动主插件
- 🔍 **自动发现**：启动自动扫描注册所有游戏，单个加载失败不影响其他游戏
- 💬 **自然语言开玩**：聊天/语音里对猫娘说游戏名或指令自动路由（LLM 工具）
- 🖥️ **玻璃拟态面板**：游戏卡片 + 开始/停止 + 配置抽屉 + 指令台，3s 自动刷新
- 🎯 **统一接口**：`GameAdapter` 基类——指令处理 / 玩家存档 / 状态上报 / 聊天推送
- 💾 **完整存档**：每玩家数据按游戏隔离存于 store，跨重启保留

## 🎮 怎么玩

聊天里直接对猫娘说游戏名即可开始：

- 「**钓鱼**」→ 抛竿钓鱼
- 「**修仙**」→ 开始修仙之旅
- 「**塔罗牌**」→ 猫娘给你占卜
- 「**猫猫进化**」→ 领养小猫开始进化

进游戏后说「**帮助**」，猫娘会发一张该游戏的指令图。完整玩法见
📖 [使用指南](docs/ui/guide.md)。

> 每个游戏的指令都是**专属命名**（猫猫状态 / 修仙状态 / 鱼店 / 海龟汤状态…），
> 不会跨游戏串台；具体指令以游戏帮助图为准。

## 🎯 内置游戏

插件启动时**自动发现** `games/` 下所有游戏——**完整清单以插件面板 / 聊天「帮助」为准**，
当前内置包括：钓鱼、海龟汤、猜硬币、俄罗斯轮盘、人生重开、诸天修仙、猫猫进化路、
塔罗牌、喵图相册、历史上的今天等。

## 📥 安装

1. 将 `neko_arcade` 发布包文件导入 `N.E.K.O` 就可以啦喵
2. 启动 N.E.K.O → 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开始游戏吧喵

## ⚙️ 配置

每个游戏自带中文配置面板：字段、类型、说明都由游戏声明，面板自动渲染。玩家存档自动存于插件 store。
