# 🎮 猫娘小游戏 (neko_arcade)

> 让猫娘陪你玩各种小游戏——一个插件，无限可能。

N.E.K.O 插件 · 插件化小游戏聚合器 · 支持聊天/语音自然语言直接开玩

## ✨ 功能特性

- 🧩 **插件化游戏架构**：`games/` 目录放一个小游戏包即完成接入，零改动主插件
- 🔍 **自动发现**：启动自动扫描注册所有游戏，单个加载失败不影响其他游戏
- 💬 **自然语言开玩**：聊天/语音里对猫娘说游戏名或指令自动路由（LLM 工具）
- 🖥️ **玻璃拟态面板**：游戏卡片 + 开始/停止 + 配置抽屉 + 指令台，3s 自动刷新
- 🎯 **统一接口**：`GameAdapter` 基类——指令处理 / 玩家存档 / 状态上报 / 聊天推送
- 💾 **完整存档**：每玩家数据按游戏隔离存于 store，跨重启保留

## 🎯 内置游戏

插件启动时**自动发现** `games/` 下所有游戏（每个文件夹 = 一个游戏，无需逐个登记）——
**完整游戏清单以插件面板 / 聊天「帮助」为准**，适配者新增游戏后无需修改任何文档。

> 每个游戏的指令都是**专属命名**（猫猫状态 / 修仙状态 / 鱼店 / 海龟汤状态…），
> 不会跨游戏串台；进游戏后说「帮助」查看指令图。
>
> 📌 **适配新游戏**：只需在 `games/` 下新增一个游戏包（含 `game.py` + `data/config/{id}/` 配置），
> 主插件零改动、文档零登记——面板自动出现，聊天直接可玩。详见 [docs/development.md](docs/development.md)。

## 📥 安装

1. 将 `neko_arcade` 发布包文件导入 `N.E.K.O`就可以啦喵
2. 启动 N.E.K.O → 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开始游戏吧喵

## ⚙️ 配置

每个游戏自带中文配置面板（`support_panel()` schema 驱动）：字段、类型、说明都由游戏声明，面板自动渲染。玩家存档自动存于插件 store。

## 🧱 架构

```
neko_arcade/
├── plugin.toml            # 插件元数据
├── __init__.py            # 主插件：生命周期 / AI 入口 / LLM 工具 / 存档
├── core/                  # 框架：契约 / 注册表 / 大脑 / 情绪 / 配置
├── adapters/              # 渲染桥 / LLM 客户端 / TTS / 推送
├── games/                 # 小游戏包（每个 = 一个小游戏）
├── static/index.html      # 前端面板
├── i18n/                  # 语言包（zh-CN）
└── docs/                  # 使用指南 / 开发文档 / 接入规则
```

### 入口点

| 类型 | id | 说明 |
|------|----|------|
| `@lifecycle` | startup / shutdown | 发现游戏 / 卸载游戏 |
| `@plugin_entry` | list_games | 游戏列表 |
| `@plugin_entry` | play_game | 玩指定游戏（AI 路由） |
| `@plugin_entry` | start_game / stop_game | 面板启动/停止会话 |
| `@plugin_entry` | game_status / game_help | 状态 / 帮助查询 |
| `@plugin_entry` | get_game_config / save_game_config | 配置读写（深度合并） |
| `@plugin_entry` | set_game_enabled | 启用/停用游戏 |
| `@plugin_entry` | get_arcade_state | 前端面板轮询 |
| `@llm_tool` | play_game | 聊天中自动路由指令 |

## 🛠️ 接入新游戏

见 [docs/development.md](docs/development.md)（开发文档）与 [docs/rules.md](docs/rules.md)（硬性契约）：

1. `games/my_game/` 建包（`__init__.py` 声明 `game_class` + `game.py` 实现 `GameAdapter`）
2. `data/config/my_game/` 放配置/帮助/关键词（命令用游戏专属前缀，防跨游戏串台）
3. 完成——**零登记**：面板自动出现游戏卡片，聊天直接可玩，无需改主插件或文档
