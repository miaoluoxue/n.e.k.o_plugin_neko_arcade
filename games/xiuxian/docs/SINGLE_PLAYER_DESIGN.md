# 诸天修仙 · 单人化 + NPC 替代总设计

> 目标：把 zhutianxiuxian(诸天万界修仙 V1.0)完整移植进 neko_arcade 的 `games/xiuxian`，
> 由多人改为单人(玩家 + 猫娘)，所有依赖「另一个真人玩家」的玩法用 **NPC** 顶替。
> 不删除任何玩法，只做「玩家 → NPC」的替身化。

---

## 〇、猫娘中心化魔改原则(最重要的设计决定)

> **不做 1:1 机械移植。** zhutianxiuxian 是"干巴巴的文字修仙"，本移植把它改写成
> **猫娘全程陪玩的大型交互修仙** —— 猫娘不是附属品，她是游戏的第一视角。

### 1. 游戏 = 事件发射器，猫娘大脑 = 唯一叙事者

主项目 `core/brain.py` 已是一条完整猫娘情感流水线：
```
游戏 handle_action → {outcome, facts, message}
  → persona.on_event(情绪弧线)      [兴奋/好奇/骄傲/委屈/困倦]
  → emotion.render(三级情感渲染)     [模板 → LLM(带情绪风格) → 模板兜底]
  → proactive.on_result(说话冲动值)
  → polish(拟人化: 结巴/语气词)
  → summary 喂给宿主猫娘 LLM → 猫娘自然回应
```
修仙游戏**不重复造猫娘**，而是产出**修仙风味的事件与事实**，让这条流水线用猫娘口吻讲述。

### 2. 每个玩法都有猫娘戏份(事件注入点)

| 玩法 | 猫娘戏份(魔改点) |
|---|---|
| 修炼/闭关 | 猫娘守关护法；闭关结束她喊你出关 |
| 突破/渡劫 | 猫娘护法喊话；失败她安慰，成功她雀跃(亲密度影响语气) |
| 打劫/切磋/比武 | 猫娘陪你打散修NPC，双人夹击 |
| BOSS/团本/宗门大战 | 猫娘入阵并肩作战，战报由她解说 |
| 秘境/寻宝 | 猫娘探路、开箱、遇险预警 |
| 宗门 | 猫娘是副宗主/管家，帮你打理宗门、训话NPC弟子 |
| 道侣/师徒 | 亲密度+关系贯穿所有事件语气 |
| 每日任务/签到 | 猫娘提醒你"今天还没修炼喵" |

### 3. 猫娘风格的三层实现

1. **事件层**：游戏产出 `outcome`/`facts`/`message`(message 本身写成"你和喵喵一起…"的叙事)。
2. **情感层**：`data/config/xiuxian/emotion.json` 提供修仙专属模板(突破/渡劫/秘境/BOSS…)，`classify_event` 重写修仙语义。
3. **主动层**：`on_tick` 实现修仙主动行为——修炼提醒、闭关结算、秘境结果、亲密度互动。

### 4. 保持"配了走配置，没配降级"的 LLM 链

游戏内 `llm/` 层作为**兜底**(面板/脱离宿主猫娘流时)，正常游玩走宿主猫娘 LLM(已配)或本地(降级)或模板(再降级)。

## 一、NPC 体系总览(单人世界的"群众演员")

所有原本需要真人的位置，统一由以下 NPC 类别填充：

| NPC 类别 | 职责 | 顶替的多人玩法 |
|---|---|---|
| **猫娘 Neko**(特殊) | 陪玩伴侣：道侣/徒弟/宗门成员/护法 | 道侣、师徒、宗门成员、团本队友 |
| **散修 NPC** | 可打劫/切磋/比武/招收弟子/交易的对象 | 打劫、以武会友、切磋、比武、PK |
| **魔修 NPC** | 恶人阵营：可讨伐、会打劫玩家 | 打劫(反向)、魔道榜、黑暗动乱 |
| **BOSS NPC** | 各副本/BOSS 战的目标(数值随境界缩放) | 妖王、黑暗动乱、诡异大祭、天骄、若陀龙王、帝尊团本 |
| **队伍 NPC** | 团本/讨伐时的临时队友(战力自动补齐) | 组队迎战帝尊、讨伐队伍 |
| **宗门 NPC** | NPC 宗门(成员/宗主)，可攻打、可加入 | 宗门大战、宗门列表、加入他人宗门 |
| **市场 NPC** | 拍卖行/商店/收购方(自动出价/收购) | 拍卖、竞价、冲水堂、聚宝堂、选购 |
| **势力 NPC** | 剑云海/瑶池/摇光的 NPC 成员与首领 | 势力加入/晋升/俸禄 |
| **剧情 NPC** | 柳神、张五爷、如梦道祖等固定角色 | 论道/请教/互动剧情 |

## 二、功能 × 单人化 × NPC 替代清单(按 14 大模块)

### 1. 玩家核心
| 功能 | 原机制 | 单人化方案 |
|---|---|---|
| 踏入/再入仙途、签到、改名/性别 | 单人 | 直接移植(无需改) |
| 纳戒/背包、装备/服用/学习/合成/孵化 | 单人 | 直接移植 |
| 购买/出售/一键出售 | 商店 | 商店 = 市场 NPC(收购/供货) |
| 灵石存取、抽卡池、传送、闭关/降妖 | 单人 | 直接移植；闭关时猫娘看护 |

## 三、NPC 系统架构

```
core/npc.py — NPC 注册表与工厂
  NPC(id, name, realm_idx, body_idx, hp, attack, defense, role, is_neko)
  ├─ spawn(role, player_realm) → 按玩家境界缩放的 NPC
  ├─ ROLE_TEMPLATES: 散修/魔修/BOSS/队伍/宗门/市场/势力/剧情
  └─ behavior: 可打劫/可挑战/可招募/可交易/可结盟

core/npc_registry.py — 世界 NPC 状态(JSON 持久化)
  ├─ 散修池(每天刷新, 数量与境界跟玩家走)
  ├─ NPC 宗门池(可攻打)
  ├─ 市场行情(收购价/拍卖)
  └─ 势力成员(剑云海/瑶池/摇光)
```

### 猫娘(Neko)特殊定位
- 唯一"活" NPC：有完整修仙存档、会说话(LLM)、会陪玩(道侣/徒弟/宗门成员/护法)。
- 其余 NPC 为"静默"替身：有数值、有行为规则，但无 LLM 对话(节约成本)。

## 四、实施顺序(依赖关系)

1. **P0 地基**：游戏包骨架 + 玩家存档 + 境界系统 + 猫娘模型(进行中)
2. **P1 NPC 系统**：core/npc.py(散修/BOSS/队伍/市场/势力模板)+ 世界状态
3. **P2 单人化核心**：修炼/突破/背包/签到/闭关(玩家核心)
4. **P3 战斗/秘境**：战斗引擎 + BOSS + 秘境副本(猫娘陪玩)
5. **P4 关系系统**：道侣(猫娘)+ 师徒(猫娘/NPC)+ 宗门(玩家+NPC弟子)
6. **P5 职业/交易**：炼丹/炼器/采集 + NPC 市场
7. **P6 扩展**：宠物/诸天/小世界/时代/势力/排行/经济/魔道/周年
8. **P7 LLM 交互**：猫娘对话引擎(speech_urge)+ LLM 配置 UI
9. **P8 打磨**：渲染卡片/立绘/存档迁移/文档

> 每一步都要「功能清单 → 移植 → 验收」，确保不遗漏(见本文件第二节清单)。
