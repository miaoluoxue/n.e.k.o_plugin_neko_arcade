# 🎮 猫娘小游戏 v0.6.2

这一版集中收口审计问题，重点修复游戏意图误触发、图库内存占用、上传边界、
多人状态稳定性和 LLM 调用兜底。

## 体验修复

- 普通聊天里提到“钓鱼”“修仙”“照片”等词，不会再把闲聊误当成游戏启动指令。
- 只有“玩钓鱼”“开始修仙”“一起玩猜硬币”等明确意图，或游戏自己的短指令，
  才会进入游戏；长句继续作为正常聊天处理。
- 用户明确索要图片时改走专用 `send_photo`，小游戏入口不再同时承担发图触发，
  避免一次请求出现双发。
- 猜硬币只认明确的“正/反”；“反正”“不正常”“heads-up”等不会误扣次数，
  旧存档缺少统计字段也会自动修复。

## 图库与上传

- 图库扫描现在只缓存路径、大小、修改时间和分类，发送时才读取图片内容；
  大图库不再把所有图片同时放进内存。
- 扫描、上传、读图和素材校验移到线程池，避免卡住宿主事件循环。
- 分类名拒绝 `.`、`..`、Windows 保留名和危险字符；文件名不再只做 basename 后静默放行。
- base64 在解码前先判断大小；单图最多 8 MiB，单次最多上传 20 张，前后端限制一致。

## 稳定性

- 共享游戏记忆改为串行写入并隔离 store 引用；一个用户写入失败，不会回滚另一个用户的数据。
- LLM 增加调用超时和统一兜底；限流、超时或 provider 异常时使用游戏原文/模板，
  不向玩家泄露底层错误。
- 会话辅助缓存增加 TTL 和数量上限，活跃游戏会话不会被淘汰。
- 主动邀请保留每会话上限，并增加插件级每日总量，避免多人环境合计刷屏。
- `data_path()` 等宿主能力缺失时，面板会显示具体降级原因和可能的数据保存风险。

## 质量门槛

- 新增 `pytest-cov` 覆盖率 CI，`fail_under=60`；缺少覆盖数据会直接失败。
- 全量 312 项测试通过，当前总覆盖率为 61.85%。
- 新增图库懒加载、上传越界、LLM 超时、并发写失败、缓存淘汰和发图限流行为测试。

## 升级

1. 从 N.E.K.O 插件市场升级到 `v0.6.2`。
2. 重启 N.E.K.O。
3. 现有配置、图库、游戏会话和存档格式保持兼容，无需迁移。
