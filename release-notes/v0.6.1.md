# 🎮 猫娘小游戏 v0.6.1

这一版集中修复审计发现的稳定性、多人隔离和素材安全问题。

## 会话与多人隔离

- 所有可变会话统一使用 `(channel, user_id)` 分槽，同一用户从 QQ、网页或本地渠道进入时，
  当前游戏、最近游戏、换游戏确认和重复回调互不覆盖。
- 游戏实例收到完整会话存档 ID；同一用户跨渠道的进度、统计和存档保持独立。
- 台词缓存、最近台词、心情、记忆、主动陪玩、活动时间和状态锚全部按会话隔离。
- 没有 `user_id` 的旧宿主环境自动回退单人模式，现有单人存档继续使用。

## 稳定性

- 后台 tick 单次异常会记录堆栈并继续运行，连续失败时指数退避，不再永久停摆。
- 游戏动作完成后，台词、记忆、里程碑、推送、卡片和会话收尾分别兜底；
  任意一步失败仍返回游戏原始结果。
- `Companion` 正确初始化并随人设热更新；没有替代台词时不再机械复读。
- gzip 截断、`EOFError` 和 store 写入失败不再静默吞掉。

## 素材安全

- 仓库内 `assets.manifest.json` 是唯一信任根，逐文件固定大小和 SHA-256。
- 只接受 HTTPS，拒绝绝对路径、`..`、盘符和 Windows 保留字符；缓存命中也会重新校验。
- 默认按需下载，失败重试后只影响当前图片，并提示“素材下载失败”。
- 素材构建工具会同步更新上传清单与仓库内信任根清单。

## 其他修复

- 棋类悔棋余量和塔罗主题按会话隔离。
- 停用游戏不能从面板直接启动。
- 裸“继续/再来/接着/再开”不再误开游戏，“玩具”不会被错误剥成“具”。
- 字体、浏览器和素材输出目录不再写死机器路径，并新增路径结构测试。

## 升级

1. 从 N.E.K.O 插件市场升级到 `v0.6.1`。
2. 重启 N.E.K.O。
3. 现有配置和单人存档保持兼容，无需迁移。
