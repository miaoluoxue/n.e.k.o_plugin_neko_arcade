# 🎮 猫娘小游戏 v0.5.8

> 这一版只干一件事：**猫娘不再「一句两答」**。

## 🐛 修好了什么

### 一次操作，只回一份结果

之前和猫娘下棋，同一份状态卡可能会出现两遍，偶尔还夹一句「有子了喵」——
你明明刚下过那一步：

```
🎴 五子棋（难度 正常）｜黑 2 手 · 白 2 手；黑暂时没有成型威胁，白有个三连苗头
🎴 五子棋（难度 正常）｜黑 2 手 · 白 2 手；黑暂时没有成型威胁，白有个三连苗头   ← 又来一遍
```

**原因**：插件的对局状态图被**当成"要读给 AI 听的内容"**发出去了（`ai_behavior="read"`）。
宿主于是把它塞进模型上下文，并且额外起了一轮；那一轮又拿着**你上一条原话**问插件
"这一步下哪"，第二次自然落在同一个点上 → 被判重复 → 于是有了第二张卡、第二句话。

**现在**：所有给用户看的推送（棋盘图 / 结算卡 / 照片 / 帮助图）都标成**只看、不喂模型**。
显示照旧（该出的图一张不少），但不会再触发额外一轮。

另外加了一道**守门**：如果同一条输入刚刚"没能推进对局"，15 秒内又来一遍，
插件直接当重复回调忽略 —— 不再执行，也不再回你第二遍。

## 🔍 会不会影响正常玩法

不会：

- 连着发「抛竿」「抛竿」照常每次都钓 —— 那是**真的推进了状态**，守门只管"没推进"的重复
- 你自己走错一步（点到已占的格子）第一次照样提示「有子了喵」
- 图、卡、状态栏的显示完全不变

## 📥 安装

1. 把下面的 `neko_arcade.neko-plugin` 导入 N.E.K.O
2. 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开玩喵
