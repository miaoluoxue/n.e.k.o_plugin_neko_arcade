# 🎮 猫娘小游戏 v0.6.0

> 这一版不加重玩法，专治**陪玩手感**：下棋能跟着棋局看图了、一局结束就回到聊天、
> 台词不再复读、多人一起玩不串台、重连回来还能接着玩。

## 🎴 下棋：每走一步都出棋盘图

以前是"关键节点 + 每 5 步才给一张"，中间几步只有一行文字，跟着下根本不知道盘面长什么样。
现在**每走一步出一张棋盘图**（默认档已改成「每走一步都出」）。

- 想省点流量/刷屏：面板里把「棋盘出图时机」选成「只关键节点」或「只看文字」；
- 老配置会自动迁移成新默认（自己手动选过的档位不会被动）；
- 说「棋盘」随时可以补一张，渲染不可用时退回文字棋盘。

## 🏁 一局结束就退出游戏模式

以前认输了、分胜负了，猫娘还挂在"对局中"—— 你得自己说「结束」才回到聊天。
现在**整局结束就自动收尾**：

- 棋类：赢 / 输 / 和 / 认输 → 自动退出，并告诉你"想再来一局直接说棋种"；
- 猜硬币、俄罗斯轮盘分出胜负，海龟汤揭晓汤底 → 同样自动收尾；
- 钓鱼、修仙、人生重开、猫猫进化、喵图相册、历史上的今天、塔罗这些**长期玩法照旧陪着**，
  不会玩一半被踢出局。

## 🗣️ 不再复读：同一件事有好几种说法

同一事件同一心情反复拿到一模一样的一句，是上一版最挨骂的点。现在：

- 每个事件缓存**多条变体轮换**（默认 4 条），最近说过的 10 句全层去重；
- 连"上一句"都不会重复，实在没得换才重新生成；
- 提示词里会告诉模型"你刚才已经说过这些"，它不会再换个语序说同一件事。

## 👥 多人一起玩不会串台

按用户各存一份"当前在玩什么"，各自的每秒钩子各跑各的；停游戏 / 切换只影响自己那一局；
当前游戏**落盘**，断线重连或重启后自动接着玩。

## 🪙 猜硬币不再乱判

只认明确的正/反（正、正面、heads / 反、反面、tails），认不出就再问一次——
**不扣次数、不算对局**（以前随便打一句话都算"反"还照样扣机会）。

## 🔧 其他

- `core/runtime.py` 的绝对导入改成相对导入 + 异常兜底：宿主 `sys.path` 不含插件目录时
  不再整个插件启动即 `ImportError`，素材库不可用只是退化为仅本地素材。
- `core/emotion.py` 删掉写死的钓鱼分支，改成通用 `<kind>_rare`/`<kind>_common` 解析——
  以后加新游戏核心零改动。
