# 🎮 猫娘小游戏 v0.5.6

> 让猫娘陪你玩的一整套小游戏——钓鱼、海龟汤、猜硬币、修仙、塔罗牌……
> 这一版把「帮助」和「出图」彻底收归插件端：**游戏只写配置，视觉/排版/主题/浏览器全由插件负责。**

## ✨ 本版亮点

### 📖 统一帮助系统（最大变化）

- **游戏只写 `help.json` 就行**：写 `groups` 就是分组帮助、只写 `commands` 就是平铺单页、
  `auto_groups: true` 才是"请插件代劳分组"——插件不会擅自改结构
- **三层寻址，用户不用记层级**：

  | 你说 | 得到 |
  |---|---|
  | 修仙帮助 | 功能目录页（11 个分组，每卡带代表指令） |
  | 修仙帮助 纳戒 / 储物 | 分组页（装备栏 + 背包格 + 指令表） |
  | 修仙帮助 装备 X | 单条指令页（用法 / 参数 / 同组其他指令） |
  | 修仙帮助 怎么装备 | 模糊匹配 → 装备 X |
  | 没命中 | 目录页 + "你是想看 XX 吗？" |

- **指令有自己的图**：「我的纳戒」直接出那张背包格图、「我的装备」出装备栏图
- **版式块**：`chips` / `table`（表头可配）/ `cards` / `stats`（进度条）/ `steps`·`flow` /
  `slots` / `bag` / `text`
- **视觉 = 官方 UI Kit**：配色与组件类名逐字取自宿主 UI Kit 样式表，素材内联、离线可用；
  目录页按内容估高自适应分页（不硬挤、不空半页）

### 🖼️ 渲染桥接：游戏不参与渲染

- 新增 `render_help` / `render_page` / `send_page`，游戏**只给数据**；`render_html` 标记废弃
- **加了 CI 守卫**：游戏侧出现 `PIL` / 浏览器 / HTML 模板 → 测试直接失败
- 人生重开原来用 400 行 PIL 画总结图 → 迁移为 `cards + stats + table` 数据，
  删掉 `drawer.py`、9 张素材和 1.9MB 像素字体

### 🐳 出图走宿主内置浏览器

优先用宿主自己的浏览器查找函数与 `PLAYWRIGHT_BROWSERS_PATH`；启动链先"不指定 exe"，
失败才退到显式路径 —— 不再要求插件自带浏览器。

### 📸 喵图相册修复

- **空图库也能出图**：兜底链 = 本地图库 → 动态猫娘表情 → 插件自带图
  （修掉"发指令不出图 / 无法自动发图"）
- 图库在 `games/neko_photo/data/`，**不进 git**，**打包默认空图库**——你的照片不会被带走
- **发图频率交给猫娘自己拿捏**，插件只兜上限：最短间隔 90s / 每小时 6 张 / 每日 50 张；
  被拦返回 `limited + retry_after`，不会连环刷屏；定时刷图默认关闭

### 💬 其它

- 聊天图片优先**内联原始字节** → 帮助图不再被 JPEG 重编码降质
- 9 个游戏补齐各自的功能分组声明（钓鱼 4 组 / 轮盘 4 组 / 人生重开 4 组 / 猫猫进化 4 组…）
- 11 个 md 文档同步更新（README / 架构 / 开发 / 规则 / 避坑 / CHANGELOG / 面板简版）

## 🎮 怎么开始

聊天里说游戏名就行：「**钓鱼**」「**修仙**」「**塔罗牌**」「**猫猫进化**」。
不会玩就说「**帮助**」，或「**修仙帮助 战斗**」这种"游戏名+帮助+玩法名"；
也可以直接说指令名（如「我的纳戒」）看那一项怎么用。

## 📥 安装

1. 把下面的 `neko_arcade.neko-plugin` 导入 N.E.K.O
2. 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开玩喵
