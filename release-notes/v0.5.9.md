# 🎮 猫娘小游戏 v0.5.9

> 这一版把**帮助图、对局卡牌图放大了一倍**——以前只到聊天窗的一半宽，现在铺开看。

## 🔍 为什么以前那么小

不是插件画小了，是**宿主的聊天窗把图片气泡宽度写死了 280px**：

```css
.message-stack      { max-width: min(86%, 320px) }   /* 所有气泡的上限 */
.message-block-image{ max-width: 280px }            /* 原生图片气泡：死的 280px */
```

而文字气泡能到 320px、聊天窗本身更宽，所以同一屏里"图只有一半宽"。
宿主给图片块也**没有点击放大**，插件画得再宽都会被压回 280px。

唯一的突破口：宿主对 **markdown 图片**没有任何宽度限制（按原始尺寸渲染）——
所以这一版把大图改走 markdown 交付。

## ✨ 现在是什么样

- **帮助图 / 对局卡牌 / 状态图默认按 480px 渲染并交付** —— 比原来的 280px 大约
  **1.7 倍**，图里的字也跟着变大变清楚（截图仍是 2 倍分辨率，约 960px PNG）
- **想更大更小都能调**：插件面板的「帮助图宽度」，或主配置
  `chat_image_width`（240–900）；调完下一次出图立即生效
- **也能强制用原生气泡**：主配置 `chat_image_mode = "native"` —— 更"贴合气泡"，
  但请注意它**永远不会超过 280px**
- 其它一切照旧：帮助分页、分组、专属图（「我的纳戒」那张）、棋盘图、塔罗牌面都不变

## ⚠️ 一点心理准备

- markdown 通路的图会**比气泡白底略宽**（图 480px / 气泡上限 320px）。
  视觉效果是"大图铺开、白底只到一半"——这是宿主 CSS 决定的取舍，
  换来的是图更大更清楚。
- 窗口很窄（或平板竖屏）时，把 `chat_image_width` 调到 **360** 左右更稳。

## 📥 安装

1. 把下面的 `neko_arcade.neko-plugin` 导入 N.E.K.O
2. 插件管理 → 启用「猫娘小游戏」
3. 直接聊天开玩喵
